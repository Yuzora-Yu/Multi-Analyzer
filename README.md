# Multi-Analyzer v4

Gold/USD・BTC/USD向けのブラウザ分析補助ツール。売買候補・目標・SL・保有ポジションのクローズ推奨をPCとスマホに表示します。

公開チャート: https://yuzora-yu.github.io/Multi-Analyzer/

## PC不要のメール監視

Cloudflare無料枠で1分間隔監視・15分確定足判定。画面とメールはBybitの同じ保存スナップショット・設定・共通エンジンを使います。[構成](cloudflare/README.md) / [条件と実データ検証](RESEARCH_V43.md)。P候補は研究段階で、プラスの期待値は未確認です。

## 起動

```powershell
python server.py
```

http://127.0.0.1:8000/ を開きます。Python 3.10+ / Node 20+。追加パッケージ不要。

[スマホ接続・Discord・メール通知の設定](SETUP.md) / [分析定義と調査元](RESEARCH.md)

## 見方

| 表示 | 意味 |
|---|---|
| 緑 ▲ 買い候補 | 確定足・スコア・コスト・上位足の条件が合致。目標とSLを併記 |
| 赤 ▼ 売り候補 | 売り方向の条件が合致 |
| 紫 × クローズ推奨 | 入力済みポジションが撤退条件に到達 |
| 灰 — 待機 | 条件未達・データ停止・見送り条件あり |

緑／赤の細いSMC帯は需要・供給の推定領域で、単独の売買指示ではありません。実線がOB、破線がFVG。矢印は構造イベント、判断バーが総合判定です。スコアは勝率ではありません。

## v4で追加・修正

- Gold / BTCだけに整理。常時表示の判断バー、スマホ対応。
- 因果的なFVG、OB、BOS、CHoCH、Sweep、Premium/Discount、EQH/EQL、前日高安、RSI divergence、推定POC。
- 従来のEMA・VWAP・ATR・ADX・RSI・MACD・Bollinger・多時間足分析にSMCを統合。
- 未確定足と確定足を分離。将来のスイングを過去に表示しない。
- データ停止時の判断抑止、取得の競合防止、ポーリング時の上位足更新。
- 資金をUSD/USDTに統一し、Goldはoz、BTCはBTCで数量計算。保有情報は銘柄別保存。
- 独立したサーバー監視とDiscord/SMTPメール通知。重複抑止・再試行・無効シグナル破棄。
- 静的配信を許可リスト化し、監視設定や通知の秘密情報を配信しない。

## データ

無料・キー不要のBybit XAUUSDT perpetual / BTCUSDT spotのローソク足で分析します。**XAUUSDのCFDやBTCUSDそのものの足ではありません。** Gold APIのUSD参考価格を別表示し、足と混ぜません。ブローカー価格に目標・SLをそのまま転用できません。

ライブ価格はWebSocket、切断時15秒ポーリング。サーバー監視は15分足・15秒間隔。ブラウザを閉じてもPC/サーバー稼働中は継続します。通知先は環境変数で設定します。現在は未設定です。

`--host 0.0.0.0` で同じWi-Fiのスマホから閲覧可能。公開チャートはGitHub Pagesから閲覧できます。メール監視はPC側の稼働が必要です。

### チャート時間足・履歴表示（2026-09-09）
1分・5分・15分・1時間・4時間・日足を選択可能。140本の描画制限を廃止し、初期表示300本／140本／取得済み全履歴を選べます。15分足は通知と同じ保存データ（約300本）、その他は最大1,000本です。配信開始日によって不足します。日足はBybitのD間隔（UTC境界）。4時間・日足は構造観察用で売買候補を発行しません。1分・5分ではP候補を発行しません。通知は引き続き共通15分確定足です。

## 比較画面・AI相談パック（2026-09-14 / UI4）

画面上部の「チャート集中」でHUDと分析パネルを閉じて価格を広く表示できます。「時間足比較・AI保存」は通常画面と独立した固定レビューです。PCは2列、スマホは1列で比較し、「根拠・アラート」では読みやすい文字で条件を確認できます。

1. 「時間足比較・AI保存」を開き、必要なら「Gold＋BTCをまとめる」を選択。
2. 「更新して固定」で15分足は共通判定を保持し、それ以外は取得開始時点の最新確定足を取得。過去の保存判定を開いた場合は全時間足を当時の基準時刻に固定。
3. 「全画像ZIP作成」→「ZIP保存」。両銘柄なら12チャートPNG＋アラート/参考プランPNG＋manifest.json＋consult-ai.txt＋確認一覧PNGの16ファイル。
4. ZIPを展開し、PNGと「相談文コピー」でコピーした文章をAIに添付。AIへの自動アップロードはありません。

チャートPNGは画面のスクリーンショットではなく、比較用の統一描画です。直近180本、8本EMAリボン、SMCイベント/活動ゾーン、15分のP、黄EXIT、出来高近似を含みます。manifestには取得した全確定足・共通設定・判定・取得エラーを保存します。15分はクラウドと同一データ/設定/エンジン。他の時間足は最大1000本の環境比較で、独立した売買通知を追加しません。Gold日足など上場後履歴の少ない市場は本数が少なくなります。

比較は更新するまで固定です。銘柄ごとの基準時刻と時間足の最終確定時刻を確認してください。古い保存判定を開いた場合は、その時点を基準に取得します。部分的な取得失敗は明示して残りを保存します。PNGはローカル生成、ZIPは依存ライブラリ不要で追加費用0円です。Safari実機検証は未実施です。

価格データ仕様：[Bybit Kline公式](https://bybit-exchange.github.io/docs/v5/market/kline)。endで取得上限時刻を指定し、未確定足を除外します。市場間の価格差、USDT建てとXMのUSD建ての違いは残ります。

## 前向き研究記録

`npm run observe:research` は毎時観測用の分析専用コマンドです。直近4つの15分保存判定を各銘柄から取得し、サインなしも含め `.runtime/hourly-observation/cohort-v1/` に保存します（Git公開対象外）。初回観測時刻、観測遅延、構造、リボン、出来高倍率、ADX、時間帯、P/EXIT/SMCイベント、品質、参考プランとその後15分/1時間/2時間/4時間の値動きを紐付けます。欠損は埋めず、未解決として残します。

7bps控除の固定保有リターンは比較用で、SL/TPや約定差を再現した取引損益ではありません。観測区間が重複するため、件数を独立試行数や勝率として扱えません。銘柄・環境別、未使用期間、取引コスト感度、期待値・ドローダウンを検証するまでは分析専用です。データ不足の段階で本番条件を変更しません。2026年の当該2市場に固有の動きを記録から評価する方針です。

既存のCodex毎時観測は実アプリ確認とこの記録を行う設定です。利用枠残り5%未満では改善作業を停止します。メールは新しいチャート確認候補のみで、アップデートだけでは送信しません。Codex観測の実行環境の可用性と、常時稼働するCloudflare通知は別です。

`node research-observer.cjs --multiframe` は比較画面と同じ取得処理で12時間足の確定OHLCVを `cohort-v1/multiframe/*.json.gz` に圧縮保存します。スマホの通常チャートは初期140本で見やすく表示し、300本・全履歴へ切替可能です。

UI5では比較画面の冒頭に6時間足の確認一覧、待機理由、20分超経過の表示を追加。ZIPにoverview.pngを追加しました。毎時研究記録には、Bybitの実約定サンプル（Gold最大1000件、BTC現物最大60件）と気配・取得範囲も保存します。連続CVDや全市場出来高としては扱いません。研究の根拠と検証方針は [RESEARCH_2026.md](RESEARCH_2026.md) を参照。
