# Multi-Analyzer Ultimate v3.1

GOLD / SILVER / BTCを対象にした、リアルタイム多時間足分析・売買候補・保有中の撤退判断・リスク計算・簡易バックテストを一画面にまとめた強化版です。

> **研究・ペーパートレード専用です。** 自動発注、投資助言、利益保証はありません。実売買前に、利用するブローカーの価格、スプレッド、手数料、スリッページ、契約サイズ、最小数量で再検証してください。


## v3.1: チャート中心UIとスマホ最適化

今回の改修では、画面全体をスクロールするダッシュボード型から、**チャートを常時表示するトレーディング端末型UI**へ変更しました。

- チャート領域をブラウザーの表示高に固定し、情報量に応じて下方向へ伸び続けない構造へ変更
- PCではチャート右側に、シグナル・売買プラン・保有判断・詳細分析を切り替えるタブパネルを配置
- スマホではチャート下部に折りたたみ式ボトムシートを配置
- ボトムシートを閉じていても、`NO TRADE / WATCH / READY / STRONG` の状態を常時表示
- セッション、レジーム、ATR、ADX、RSI、データ品質をチャート上のHUDに表示
- タッチ操作用ボタンを拡大し、入力欄はスマホで数値キーボードを使用
- チャートのズーム・表示位置をリアルタイム更新のたびにリセットしないよう変更
- `ResizeObserver` の反映を寸法変更時だけに限定し、破棄時に必ず切断

スマホでは、下部のシグナルバーをタップすると分析パネルが開きます。上部タブから「シグナル」「プラン」「保有」「詳細」を切り替えられます。

## 起動方法

Python 3だけで起動できます。

```bash
cd Multi-Analyzer-Ultimate
python server.py
```

ブラウザーで次を開きます。

```text
http://127.0.0.1:8000/
```

Windowsでは `start.bat`、macOS / Linuxでは `start.command` も使用できます。

## 今回の主な強化

### 1. 「私ならどうするか」をリアルタイム表示

確定足を基準に、次の状態を表示します。

| 状態 | 意味 |
|---|---|
| `NO_TRADE` | hard veto、スコア不足、方向差不足、コスト後R:R不足などで見送り |
| `WATCH_LONG / WATCH_SHORT` | 方向優位はあるが確定トリガー待ち |
| `READY_LONG / READY_SHORT` | 最低スコア、確定トリガー、コスト、上位足整合を通過 |
| `STRONG_LONG / STRONG_SHORT` | 強い多時間足合致 |

画面上では `BUY SETUP`、`SELL SETUP`、`WATCH BUY`、`WATCH SELL`、`WAIT / NO TRADE` として表示します。

### 2. 形成中プレビューと確定足判定を分離

WebSocketで価格はリアルタイム更新しますが、新規候補の正式判定は確定足だけを使います。

- **確定足シグナル:** 注文候補の基準
- **形成中プレビュー:** 現在の足がこのまま確定した場合の参考表示

未確定足の途中でBUY / SELLが頻繁に反転する問題を抑える設計です。

### 3. 保有中のHOLD / REDUCE / TRAIL / EXIT

方向、建値、ストップを入力するとライブ価格で更新します。

- `HOLD_LONG / HOLD_SHORT`: 保有方向の優位を維持
- `REDUCE_LONG / REDUCE_SHORT`: 構造転換が出たため縮小候補
- `TRAIL_LONG / TRAIL_SHORT`: 利益が伸び、モメンタム鈍化時に追随ストップ候補
- `EXIT_LONG / EXIT_SHORT`: ストップ到達、反対方向の確定シグナル、上位足反転など

### 4. LONG / SHORTの独立採点

一方向を先に決めて加点するのではなく、LONGとSHORTを別々に0–100点で採点します。

主な評価要素:

- 4H / 1H / 15m / 執行足のトレンド
- EMA20 / EMA50 / EMA200と傾き
- BOS / CHoCH、確定スイング
- 流動性スイープ
- ローソク足リジェクション、包み足
- RSI、MACDヒストグラム、ADX、+DI / -DI
- ATR順位、ボリンジャーバンド幅、相場レジーム
- ローリングVWAP、日次VWAP、週次VWAP
- 出来高Zスコア
- London / New York / Overlapセッション
- Bid / Askスプレッド、板厚偏り
- 先物のマーク価格・指数価格乖離、資金調達率

### 5. hard veto

スコアより先に、取引禁止条件を評価します。

- データ不足、古い足、複数の時間ギャップ
- 手動の重要指標ブラックアウト
- NYロールオーバー周辺
- 1H / 4Hに逆行する新規候補
- 上下方向への伸び切り
- ATR急拡大
- LONG / SHORTの優位差不足
- コストがストップ幅に対して過大
- コスト控除後R:R不足
- マーク価格と指数価格の極端な乖離
- 極端な資金調達率

### 6. リスク計算

設定画面で次を変更できます。

- 口座資金
- 1回の許容損失率
- 片道手数料
- 想定スプレッド
- 想定スリッページ
- 最低コスト後R:R
- 最大レバレッジ
- 重要指標ブラックアウト

表示される数量は、許容損失額とストップ距離から逆算し、最大レバレッジでも上限をかけます。

### 7. 保守的バックテスト

現在読み込まれた確定足の最大1,200本を、Web Worker内で検証します。

- シグナル足の次足始値で約定
- 同一足でストップと利確に触れた場合はストップ優先
- TP1で50%、TP2で30%、TP3で残りを決済
- TP1後は建値＋想定コストへ移動
- 最大保有時間あり
- 損切り後クールダウン
- 2連敗後はクールダウン延長
- 日次損失上限
- 手数料、スプレッド、スリッページをR損益へ反映
- 70% In-Sample / 30% Out-of-Sampleを分離

過去成績は将来の利益を保証しません。ブラウザー内の簡易検証であり、実運用前にはより長い期間・複数相場環境で再検証してください。

## データ

通常は `server.py` が次の公開データだけを限定プロキシします。

- Binance Kline
- Book Ticker（Bid / Askと数量）
- Futures Premium Index（マーク価格、指数価格、資金調達率）

APIキー、口座情報、注文APIは使用しません。注文機能はありません。

既定銘柄:

- GOLD: `XAUUSDT` USDⓈ-M Futures
- SILVER: `XAGUSDT` USDⓈ-M Futures
- BTC: `BTCUSDT` Spot

これらは、OTCのXAUUSD / XAGUSD、COMEX先物、各CFDブローカーの価格や出来高とは一致しません。

## CSVモード

画面右上の `CSV` から読み込めます。

必要列:

```csv
time,open,high,low,close,volume
2026-07-01T00:00:00Z,3300.1,3302.5,3298.8,3301.7,1200
```

`time` はISO日時、Unix秒、Unixミリ秒に対応します。列名は `timestamp`、`date` でも構いません。

`sample-data.csv` は動作確認用の合成データで、実相場データではありません。

## 重要な限界

- 経済指標カレンダーは自動取得しません。設定から手動ブラックアウトしてください。
- 世界全体のGold / Silver出来高ではなく、取得先市場の出来高です。
- 注文板は最良Bid / Askの数量だけで、フル板ではありません。
- ニュース、COT、オプションIV、実ブローカーの約定品質は統合していません。
- ブラウザーやネットワーク環境によりWebSocketが遮断される場合、15秒ポーリングへ切り替わります。
- 自動発注は安全上、意図的に実装していません。

最低4–8週間のペーパートレードを行い、シグナル時刻、提示Entry、実際に約定可能だった価格、最大逆行、最大順行、実コストを記録してから評価してください。
